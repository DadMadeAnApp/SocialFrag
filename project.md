# SocialFrag

Free Windows game-clip editor: raw gameplay → 9:16 vertical via presets (default), or 16:9 landscape full frame. Offline Whisper auto-captions. Tauri 2 + React + bundled ffmpeg. Open source (GPL-3.0), DadMadeAnApp.
