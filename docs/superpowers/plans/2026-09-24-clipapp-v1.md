# SocialFrag v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a free Windows desktop app that turns a gameplay clip into a 1080×1920 vertical MP4 using game presets, with trim, a preset editor and text captions.

**Architecture:** Tauri 2 shell. The React/TypeScript UI draws a live preview on a `<canvas>` from a hidden `<video>`. A Rust core runs a bundled ffmpeg/ffprobe for probing, preview proxies and export. Crop/placement math is implemented twice (TS `render/fit.ts`, Rust `preset.rs`) against the same fixture numbers, so preview and export agree. Rounded corners, borders and captions are rendered to PNG by the UI (same drawing code as the preview) and overlaid by ffmpeg.

**Tech Stack:** Tauri 2, Rust (serde, serde_json, base64), React + TypeScript + Vite, Vitest + jsdom + Testing Library, ffmpeg 7.x (BtbN LGPL build), @fontsource (Inter, Anton, Bebas Neue).

**Spec:** `docs/superpowers/specs/2026-09-24-clipapp-design.md`

## Global Constraints

- Target: Windows 10/11 x64 only. Installer: NSIS, per-user install.
- Product name `SocialFrag`. Identifier `com.dadmadeanapp.socialfrag`.
- Code repo `DadMadeAnApp/socialfrag` (private). Installers + updater feed: `DadMadeAnApp/socialfrag-releases` (public).
- Contacts: `support@dadmadeanapp.com`, `privacy@dadmadeanapp.com`.
- Output: 1080×1920 H.264 MP4, fps = source fps capped at 60, AAC 192 kbps, `+faststart`.
- Preset `version: 1`; `src` = `[x,y,w,h]` fractions 0–1 of source frame; `dst` = `[x,y,w,h]` output pixels on the 1080×1920 canvas; layers draw bottom to top.
- Never overwrite an existing file: `<stem>_vertical.mp4`, then `<stem>_vertical-1.mp4`, `-2`, …
- No network calls except the Tauri updater check. No telemetry, no accounts.
- Bundled open-license fonts only: Inter, Anton, Bebas Neue.
- Dev happens on macOS (Homebrew ffmpeg at `/opt/homebrew/bin/ffmpeg` works for `tauri dev` and ignored integration tests). Release builds and GPU encoder testing happen on the Windows PC.

## Review Focus

1. **Variable / high frame-rate sources** (ShadowPlay VFR, 144/240 fps, `60000/1001`): export must be constant-rate ≤60 fps. Pinned in Task 12 (`fps_*` tests).
2. **Paths with spaces, apostrophes, unicode** (`C:\Users\José\Videos\Bob's clip.mp4`): must probe, export and name the output correctly. Pinned in Task 12 (source path stays one argv element) and Task 13 (`unique_output_path_unicode`).
3. **Clips with no audio track**: export must still succeed. Pinned in Task 12 (`-map 0:a?` test with `has_audio: false`).
4. **Captions outside the trimmed range**: a caption that starts after trim-out is dropped; one that starts before trim-in shows from frame 0. Pinned in Task 12 (`overlay_timing_relative_to_trim`) and Task 10.
5. **Odd source sizes / regions touching the frame edge** (2559×1439, `src` ending at exactly 1.0): crop must stay inside the frame. Pinned in Task 3 and Task 11 (`edge_clamp` tests).

```ts
import { CANVAS_H, CANVAS_W, type Background, type Fit, type Layer, type Preset, type Rect } from '../types';

export type ValidationResult = { ok: true; preset: Preset } | { ok: false; error: string };

const EPS = 1e-6;

export const isHexColor = (s: unknown): s is string => typeof s === 'string' && /^#[0-9a-fA-F]{6}$/.test(s);

const isRect = (v: unknown): v is Rect =>
  Array.isArray(v) && v.length === 4 && v.every((n) => typeof n === 'number' && Number.isFinite(n));

function parseBackground(v: any): Background | string {
  if (!v || typeof v !== 'object') return 'background missing';
  if (v.type === 'blur') {
    return typeof v.amount === 'number' && v.amount >= 0 && v.amount <= 100 ? { type: 'blur', amount: v.amount } : 'blur amount must be 0-100';
  }
  if (v.type === 'color') return isHexColor(v.color) ? { type: 'color', color: v.color } : 'background color must be #RRGGBB';
  if (v.type === 'none') return { type: 'none' };
  return `unknown background type ${String(v.type)}`;
}

function parseLayer(v: any, i: number): Layer | string {
  if (!v || typeof v !== 'object') return `layer ${i} is not an object`;
  if (typeof v.id !== 'string' || !v.id) return `layer ${i} needs an id`;
  const id: string = v.id;
  if (!isRect(v.src)) return `layer ${id}: src must be 4 numbers`;
  const [x, y, w, h] = v.src;
  if (x < 0 || y < 0 || w <= 0 || h <= 0 || x + w > 1 + EPS || y + h > 1 + EPS) return `layer ${id}: src outside frame`;
  if (!isRect(v.dst)) return `layer ${id}: dst must be 4 numbers`;
  const [dx, dy, dw, dh] = v.dst;
  if (dx < 0 || dy < 0 || dw < 1 || dh < 1 || dx + dw > CANVAS_W || dy + dh > CANVAS_H) return `layer ${id}: dst outside canvas`;
  if (v.fit !== undefined && v.fit !== 'cover' && v.fit !== 'contain') return `layer ${id}: fit must be cover or contain`;
  const fit: Fit = v.fit === 'contain' ? 'contain' : 'cover';
  const layer: Layer = { id, label: typeof v.label === 'string' && v.label ? v.label : id, src: [x, y, w, h], dst: [dx, dy, dw, dh], fit };
  if (v.radius !== undefined) {
    if (typeof v.radius !== 'number' || !Number.isFinite(v.radius) || v.radius < 0) return `layer ${id}: radius must be >= 0`;
    layer.radius = v.radius;
  }
  if (v.border !== undefined) {
    const b = v.border;
    if (!b || typeof b.width !== 'number' || !(b.width > 0) || !isHexColor(b.color)) return `layer ${id}: border needs width > 0 and #RRGGBB color`;
    layer.border = { width: b.width, color: b.color };
  }
  return layer;
}

export function validatePreset(raw: unknown): ValidationResult {
  const v = raw as any;
  if (!v || typeof v !== 'object') return { ok: false, error: 'preset is not an object' };
  if (v.version !== 1) return { ok: false, error: `unsupported preset version ${String(v.version)}` };
  if (typeof v.id !== 'string' || !v.id) return { ok: false, error: 'preset needs an id' };
  if (typeof v.name !== 'string' || !v.name) return { ok: false, error: 'preset needs a name' };
  const background = parseBackground(v.background);
  if (typeof background === 'string') return { ok: false, error: background };
  if (!Array.isArray(v.layers) || v.layers.length === 0) return { ok: false, error: 'preset needs at least one layer' };
  const layers: Layer[] = [];
  const seen = new Set<string>();
  for (let i = 0; i < v.layers.length; i++) {
    const l = parseLayer(v.layers[i], i);
    if (typeof l === 'string') return { ok: false, error: l };
    if (seen.has(l.id)) return { ok: false, error: `duplicate layer id ${l.id}` };
    seen.add(l.id);
    layers.push(l);
  }
  return {
    ok: true,
    preset: { id: v.id, name: v.name, game: typeof v.game === 'string' ? v.game : '', version: 1, builtin: v.builtin === true, background, layers },
  };
}
```

```ts
  const presets: Preset[] = [];
  const warnings: string[] = [];
  const ids = new Set(BUILTIN_PRESETS.map((p) => p.id));
```

```ts
import type { Layer, Rect } from '../types';

export interface LayerLayout { crop: Rect; draw: Rect }

const clamp = (v: number, lo: number, hi: number) => Math.min(hi, Math.max(lo, v));

/** Mirrors src-tauri/src/preset.rs `layout_layer` exactly. Change both together. */
export function layoutLayer(layer: Pick<Layer, 'src' | 'dst' | 'fit'>, srcW: number, srcH: number): LayerLayout {
  const { src, dst, fit } = layer;
  let x = clamp(Math.round(src[0] * srcW), 0, srcW - 1);
  let y = clamp(Math.round(src[1] * srcH), 0, srcH - 1);
  let w = clamp(Math.round(src[2] * srcW), 1, srcW - x);
  let h = clamp(Math.round(src[3] * srcH), 1, srcH - y);
  const [dx, dy, dw, dh] = dst.map(Math.round) as Rect;

  if (fit === 'cover') {
    const a = dw / dh;
    if (w / h > a) {
      const nw = Math.max(1, Math.round(h * a));
      x += Math.round((w - nw) / 2);
      w = nw;
    } else {
      const nh = Math.max(1, Math.round(w / a));
      y += Math.round((h - nh) / 2);
      h = nh;
    }
    return { crop: [x, y, w, h], draw: [dx, dy, dw, dh] };
  }

  const s = Math.min(dw / w, dh / h);
  const drawW = Math.max(1, Math.round(w * s));
  const drawH = Math.max(1, Math.round(h * s));
  return { crop: [x, y, w, h], draw: [dx + Math.round((dw - drawW) / 2), dy + Math.round((dh - drawH) / 2), drawW, drawH] };
}
```

```ts
/** Fake 2D context: records calls and property sets; measureText = 10px per character. */
export function recordingCtx() {
  const calls: { name: string; args: unknown[] }[] = [];
  const props: Record<string, unknown> = {};
  const ctx = new Proxy(
    {},
    {
      get: (_t, key: string | symbol) => {
        const name = String(key);
        if (name in props) return props[name];
        if (name === 'measureText') return (s: string) => ({ width: s.length * 10 });
        return (...args: unknown[]) => {
          calls.push({ name, args });
        };
      },
      set: (_t, key: string | symbol, value: unknown) => {
        props[String(key)] = value;
        calls.push({ name: `set:${String(key)}`, args: [value] });
        return true;
      },
    },
  );
  return { ctx: ctx as unknown as CanvasRenderingContext2D, calls, named: (n: string) => calls.filter((c) => c.name === n).map((c) => c.args) };
}
```

```ts
import type { Caption, CaptionStyle } from '../types';
import type { Ctx2D } from './ctx';

export const CAPTION_MAX_W = 960;
export const LINE_HEIGHT = 1.15;
export const HANDLE = 28;

interface StyleDef {
  font(size: number): string;
  fill: string;
  stroke?: { color: string; width(size: number): number };
  box?: { color: string; padX(size: number): number; padY(size: number): number; radius(size: number): number };
}

export const CAPTION_STYLES: Record<CaptionStyle, StyleDef> = {
  tiktok: { font: (s) => `800 ${s}px Inter`, fill: '#ffffff', stroke: { color: '#000000', width: (s) => s * 0.12 } },
  impact: { font: (s) => `${s}px Anton`, fill: '#ffe14d', stroke: { color: '#000000', width: (s) => s * 0.1 } },
  boxed: {
    font: (s) => `${s}px "Bebas Neue"`,
    fill: '#ffffff',
    box: { color: 'rgba(0,0,0,0.75)', padX: (s) => s * 0.4, padY: (s) => s * 0.25, radius: (s) => s * 0.3 },
  },
  plain: { font: (s) => `600 ${s}px Inter`, fill: '#ffffff' },
};

export const STYLE_LABELS: Record<CaptionStyle, string> = { tiktok: 'TikTok', impact: 'Impact', boxed: 'Boxed', plain: 'Plain' };

export interface Box { x: number; y: number; w: number; h: number }

export function wrapLines(measure: (s: string) => number, text: string, maxW: number): string[] {
  const out: string[] = [];
  for (const para of text.split('\n')) {
    const words = para.split(/\s+/).filter(Boolean);
    if (words.length === 0) {
      out.push('');
      continue;
    }
    let line = words[0];
    for (const word of words.slice(1)) {
      const next = `${line} ${word}`;
      if (measure(next) <= maxW) line = next;
      else {
        out.push(line);
        line = word;
      }
    }
    out.push(line);
  }
  return out;
}

export function captionLayout(ctx: Ctx2D, c: Caption): { lines: string[]; box: Box } {
  const st = CAPTION_STYLES[c.style];
  ctx.font = st.font(c.fontSize);
  const lines = wrapLines((s) => ctx.measureText(s).width, c.text, CAPTION_MAX_W);
  const textW = Math.max(1, ...lines.map((l) => ctx.measureText(l).width));
  const lh = c.fontSize * LINE_HEIGHT;
  const padX = st.box ? st.box.padX(c.fontSize) : 0;
  const padY = st.box ? st.box.padY(c.fontSize) : 0;
  const w = textW + padX * 2;
  const h = lh * lines.length + padY * 2;
  return { lines, box: { x: c.x - w / 2, y: c.y - h / 2, w, h } };
}

export function drawCaption(ctx: Ctx2D, c: Caption): void {
  if (!c.text.trim()) return;
  const st = CAPTION_STYLES[c.style];
  const { lines, box } = captionLayout(ctx, c);
  ctx.save();
  if (st.box) {
    ctx.fillStyle = st.box.color;
    ctx.beginPath();
    ctx.roundRect(box.x, box.y, box.w, box.h, st.box.radius(c.fontSize));
    ctx.fill();
  }
  ctx.font = st.font(c.fontSize);
  ctx.textAlign = 'center';
  ctx.textBaseline = 'middle';
  ctx.lineJoin = 'round';
  const lh = c.fontSize * LINE_HEIGHT;
  const top = c.y - (lh * lines.length) / 2 + lh / 2;
  lines.forEach((line, i) => {
    const y = top + i * lh;
    if (st.stroke) {
      ctx.strokeStyle = st.stroke.color;
      ctx.lineWidth = st.stroke.width(c.fontSize);
      ctx.strokeText(line, c.x, y);
    }
    ctx.fillStyle = st.fill;
    ctx.fillText(line, c.x, y);
  });
  ctx.restore();
}

export const isCaptionVisible = (c: Caption, t: number): boolean => t >= c.start - 1e-3;

export function hitCaption(ctx: Ctx2D, captions: Caption[], x: number, y: number): { id: string; mode: 'move' | 'resize' } | null {
  for (let i = captions.length - 1; i >= 0; i--) {
    const { box } = captionLayout(ctx, captions[i]);
    const right = box.x + box.w;
    const bottom = box.y + box.h;
    if (Math.abs(x - right) <= HANDLE && Math.abs(y - bottom) <= HANDLE) return { id: captions[i].id, mode: 'resize' };
    if (x >= box.x && x <= right && y >= box.y && y <= bottom) return { id: captions[i].id, mode: 'move' };
  }
  return null;
}

export function drawCaptionSelection(ctx: Ctx2D, c: Caption): void {
  const { box } = captionLayout(ctx, c);
  ctx.save();
  ctx.strokeStyle = '#4da3ff';
  ctx.lineWidth = 4;
  ctx.setLineDash([12, 8]);
  ctx.strokeRect(box.x, box.y, box.w, box.h);
  ctx.setLineDash([]);
  ctx.fillStyle = '#4da3ff';
  ctx.fillRect(box.x + box.w - HANDLE / 2, box.y + box.h - HANDLE / 2, HANDLE, HANDLE);
  ctx.restore();
}
```

```ts
import { CANVAS_H, CANVAS_W, type Background, type Caption, type Layer, type Preset } from '../types';
import { drawCaption, isCaptionVisible } from './captions';
import type { Ctx2D } from './ctx';
import { layoutLayer } from './fit';

export function drawBackground(ctx: Ctx2D, frame: CanvasImageSource, srcW: number, srcH: number, bg: Background): void {
  if (bg.type === 'blur') {
    const { crop } = layoutLayer({ src: [0, 0, 1, 1], dst: [0, 0, CANVAS_W, CANVAS_H], fit: 'cover' }, srcW, srcH);
    ctx.save();
    ctx.filter = `blur(${bg.amount}px)`;
    ctx.drawImage(frame, crop[0], crop[1], crop[2], crop[3], 0, 0, CANVAS_W, CANVAS_H);
    ctx.restore();
    return;
  }
  ctx.fillStyle = bg.type === 'color' ? bg.color : '#000000';
  ctx.fillRect(0, 0, CANVAS_W, CANVAS_H);
}

export function drawLayerImage(ctx: Ctx2D, frame: CanvasImageSource, srcW: number, srcH: number, layer: Layer): void {
  const { crop, draw } = layoutLayer(layer, srcW, srcH);
  ctx.save();
  if (layer.radius) {
    ctx.beginPath();
    ctx.roundRect(draw[0], draw[1], draw[2], draw[3], layer.radius);
    ctx.clip();
  }
  ctx.drawImage(frame, crop[0], crop[1], crop[2], crop[3], draw[0], draw[1], draw[2], draw[3]);
  ctx.restore();
}

export function drawLayerBorder(ctx: Ctx2D, srcW: number, srcH: number, layer: Layer): void {
  if (!layer.border) return;
  const { draw } = layoutLayer(layer, srcW, srcH);
  ctx.save();
  ctx.strokeStyle = layer.border.color;
  ctx.lineWidth = layer.border.width;
  ctx.beginPath();
  ctx.roundRect(draw[0], draw[1], draw[2], draw[3], layer.radius ?? 0);
  ctx.stroke();
  ctx.restore();
}

/** White = visible. Used by ffmpeg alphamerge for rounded corners. */
export function drawMask(ctx: Ctx2D, w: number, h: number, radius: number): void {
  ctx.fillStyle = '#000000';
  ctx.fillRect(0, 0, w, h);
  ctx.fillStyle = '#ffffff';
  ctx.beginPath();
  ctx.roundRect(0, 0, w, h, radius);
  ctx.fill();
}

export function drawFrame(ctx: Ctx2D, frame: CanvasImageSource, srcW: number, srcH: number, preset: Preset, captions: Caption[], t: number): void {
  drawBackground(ctx, frame, srcW, srcH, preset.background);
  for (const l of preset.layers) drawLayerImage(ctx, frame, srcW, srcH, l);
  for (const l of preset.layers) drawLayerBorder(ctx, srcW, srcH, l);
  for (const c of captions) if (isCaptionVisible(c, t)) drawCaption(ctx, c);
}
```

```ts
import { presetFileName } from '../presets/presets';
import type { ClipInfo, ExportError, ExportJob, ExportProgress, ExportResult, Preset, RawPresetFile } from '../types';
import type { Backend } from './types';

const STORE_KEY = 'socialfrag.fake.presets';

function pickFile(accept: string): Promise<File | null> {
  return new Promise((resolve) => {
    const input = document.createElement('input');
    input.type = 'file';
    input.accept = accept;
    input.onchange = () => resolve(input.files?.[0] ?? null);
    input.click();
  });
}

/** Browser-only backend so the UI can be built and tested on the Mac without Tauri. */
export class FakeBackend implements Backend {
  readonly kind = 'fake' as const;
  private urls = new Map<string, string>();
  private cancelled = false;

  private register(file: File): string {
    const path = `fake://${file.name}`;
    this.urls.set(path, URL.createObjectURL(file));
    return path;
  }

  async pickClip() {
    const f = await pickFile('video/*');
    return f ? this.register(f) : null;
  }

  async pickFolder() {
    return 'fake://exports';
  }

  videoUrl(path: string) {
    const url = this.urls.get(path);
    if (!url) throw new Error(`unknown fake path ${path}`);
    return url;
  }

  probe(path: string): Promise<ClipInfo> {
    return new Promise((resolve, reject) => {
      const v = document.createElement('video');
      v.preload = 'metadata';
      v.onloadedmetadata = () => resolve({ width: v.videoWidth, height: v.videoHeight, fps: '60', codec: 'h264', duration: v.duration, hasAudio: true });
      v.onerror = () => reject(new Error("This file isn't a video SocialFrag can read."));
      v.src = this.videoUrl(path);
    });
  }

  async makeProxy(path: string) {
    return path;
  }

  private readStore(): Record<string, string> {
    try {
      const parsed = JSON.parse(localStorage.getItem(STORE_KEY) ?? '{}');
      return parsed && typeof parsed === 'object' ? parsed : {};
    } catch {
      return {};
    }
  }

  private writeStore(s: Record<string, string>) {
    try {
      localStorage.setItem(STORE_KEY, JSON.stringify(s));
    } catch {
      /* storage blocked: presets live for this page only */
    }
  }

  async listUserPresets(): Promise<RawPresetFile[]> {
    return Object.entries(this.readStore()).map(([id, contents]) => ({ file: `${id}.json`, contents }));
  }

  async savePreset(p: Preset) {
    const s = this.readStore();
    s[p.id] = JSON.stringify(p);
    this.writeStore(s);
  }

  async deletePreset(id: string) {
    const s = this.readStore();
    delete s[id];
    this.writeStore(s);
  }

  async importPreset() {
    const f = await pickFile('.json,application/json');
    return f ? f.text() : null;
  }

  async exportPreset(p: Preset) {
    const a = document.createElement('a');
    a.href = URL.createObjectURL(new Blob([JSON.stringify(p, null, 2)], { type: 'application/json' }));
    a.download = presetFileName(p);
    a.click();
  }

  startExport(job: ExportJob, onProgress: (p: ExportProgress) => void): Promise<ExportResult> {
    this.cancelled = false;
    return new Promise((resolve, reject) => {
      let f = 0;
      const timer = setInterval(() => {
        if (this.cancelled) {
          clearInterval(timer);
          const err: ExportError = { code: 'cancelled', message: 'Export cancelled.', details: '' };
          reject(err);
          return;
        }
        f = Math.min(1, Math.round((f + 0.1) * 10) / 10);
        onProgress({ fraction: f, etaS: (1 - f) * 2 });
        if (f >= 1) {
          clearInterval(timer);
          resolve({ outputPath: `${job.source.replace(/\.[^.]+$/, '')}_vertical.mp4`, usedCpuFallback: false });
        }
      }, 200);
    });
  }

  async cancelExport() {
    this.cancelled = true;
  }

  async revealFile(path: string) {
    console.info('reveal', path);
  }

  onFileDrop(cb: (path: string) => void) {
    const over = (e: DragEvent) => e.preventDefault();
    const drop = (e: DragEvent) => {
      e.preventDefault();
      const f = e.dataTransfer?.files[0];
      if (f) cb(this.register(f));
    };
    window.addEventListener('dragover', over);
    window.addEventListener('drop', drop);
    return () => {
      window.removeEventListener('dragover', over);
      window.removeEventListener('drop', drop);
    };
  }
}
```

```ts
import { CANVAS_H, CANVAS_W, type Caption } from '../types';

const clamp = (v: number, lo: number, hi: number) => Math.min(hi, Math.max(lo, v));

export function newCaption(id: string, currentTime: number, timing: 'whole' | 'fromHere'): Caption {
  return { id, text: 'Your caption', style: 'tiktok', x: CANVAS_W / 2, y: 260, fontSize: 80, start: timing === 'whole' ? 0 : currentTime };
}

export const updateCaption = (list: Caption[], c: Caption): Caption[] => list.map((x) => (x.id === c.id ? c : x));
export const removeCaption = (list: Caption[], id: string): Caption[] => list.filter((x) => x.id !== id);

export const moveCaption = (c: Caption, dx: number, dy: number): Caption => ({
  ...c,
  x: clamp(c.x + dx, 0, CANVAS_W),
  y: clamp(c.y + dy, 0, CANVAS_H),
});

export const resizeCaption = (c: Caption, dy: number): Caption => ({ ...c, fontSize: clamp(Math.round(c.fontSize + dy * 0.5), 24, 240) });
```

```tsx
import { useEffect, useRef, type PointerEvent } from 'react';
import { drawCaptionSelection, hitCaption } from '../render/captions';
import { drawFrame } from '../render/compose';
import { moveCaption, resizeCaption } from '../state/captions';
import { CANVAS_H, CANVAS_W, type Caption, type ClipInfo, type Preset } from '../types';

interface Props {
  video: HTMLVideoElement | null;
  info: ClipInfo;
  preset: Preset;
  captions: Caption[];
  selectedCaptionId: string | null;
  onSelectCaption(id: string | null): void;
  onCaptionChange(c: Caption): void;
}

export function PreviewCanvas({ video, info, preset, captions, selectedCaptionId, onSelectCaption, onCaptionChange }: Props) {
  const canvasRef = useRef<HTMLCanvasElement>(null);
  const latest = useRef({ preset, captions, selectedCaptionId });
  latest.current = { preset, captions, selectedCaptionId };
  const drag = useRef<{ mode: 'move' | 'resize'; x: number; y: number; orig: Caption } | null>(null);

  useEffect(() => {
    const ctx = canvasRef.current?.getContext('2d');
    if (!ctx || !video) return;
    let raf = 0;
    const tick = () => {
      const { preset, captions, selectedCaptionId } = latest.current;
      if (video.readyState >= 2) drawFrame(ctx, video, info.width, info.height, preset, captions, video.currentTime);
      const sel = captions.find((c) => c.id === selectedCaptionId);
      if (sel) drawCaptionSelection(ctx, sel);
      raf = requestAnimationFrame(tick);
    };
    raf = requestAnimationFrame(tick);
    return () => cancelAnimationFrame(raf);
  }, [video, info]);

  const toCanvas = (e: PointerEvent) => {
    const r = canvasRef.current!.getBoundingClientRect();
    return { x: ((e.clientX - r.left) * CANVAS_W) / r.width, y: ((e.clientY - r.top) * CANVAS_H) / r.height };
  };

  const onPointerDown = (e: PointerEvent<HTMLCanvasElement>) => {
    const ctx = canvasRef.current?.getContext('2d');
    if (!ctx) return;
    const p = toCanvas(e);
    const hit = hitCaption(ctx, captions, p.x, p.y);
    if (!hit) {
      onSelectCaption(null);
      return;
    }
    const orig = captions.find((c) => c.id === hit.id)!;
    onSelectCaption(orig.id);
    drag.current = { mode: hit.mode, x: p.x, y: p.y, orig };
    e.currentTarget.setPointerCapture(e.pointerId);
  };

  const onPointerMove = (e: PointerEvent<HTMLCanvasElement>) => {
    const d = drag.current;
    if (!d) return;
    const p = toCanvas(e);
    onCaptionChange(d.mode === 'move' ? moveCaption(d.orig, p.x - d.x, p.y - d.y) : resizeCaption(d.orig, p.y - d.y));
  };

  return (
    <canvas
      ref={canvasRef}
      className="preview"
      width={CANVAS_W}
      height={CANVAS_H}
      aria-label="Vertical preview"
      onPointerDown={onPointerDown}
      onPointerMove={onPointerMove}
      onPointerUp={() => (drag.current = null)}
      onDoubleClick={() => document.getElementById('caption-text')?.focus()}
    />
  );
}
```

```tsx
import { useCallback, useEffect, useMemo, useState } from 'react';
import type { Backend } from './backend/types';
import { PresetRail } from './components/PresetRail';
import { PreviewCanvas } from './components/PreviewCanvas';
import { BUILTIN_PRESETS, blankPreset, duplicatePreset, loadUserPresets } from './presets/presets';
import { validatePreset } from './presets/validate';
import { updateCaption } from './state/captions';
import type { Caption, ClipInfo, Preset } from './types';

export interface LoadedClip { path: string; url: string; info: ClipInfo; proxied: boolean }

const message = (e: unknown) => (e instanceof Error ? e.message : String(e));

export function App({ backend }: { backend: Backend }) {
  const [clip, setClip] = useState<LoadedClip | null>(null);
  const [video, setVideo] = useState<HTMLVideoElement | null>(null);
  const [error, setError] = useState<string | null>(null);
  const [busy, setBusy] = useState<string | null>(null);
  const [userPresets, setUserPresets] = useState<Preset[]>([]);
  const [warnings, setWarnings] = useState<string[]>([]);
  const [presetId, setPresetId] = useState(BUILTIN_PRESETS[0].id);
  const [captions, setCaptions] = useState<Caption[]>([]);
  const [selectedCaptionId, setSelectedCaptionId] = useState<string | null>(null);
  const [draft, setDraft] = useState<Preset | null>(null);

  const allPresets = useMemo(() => [...BUILTIN_PRESETS, ...userPresets], [userPresets]);
  const preset = allPresets.find((p) => p.id === presetId) ?? BUILTIN_PRESETS[0];

  const refreshPresets = useCallback(async () => {
    const loaded = loadUserPresets(await backend.listUserPresets());
    setUserPresets(loaded.presets);
    setWarnings(loaded.warnings);
  }, [backend]);

  useEffect(() => {
    void refreshPresets();
  }, [refreshPresets]);

  const loadClip = useCallback(
    async (path: string) => {
      setError(null);
      setBusy('Opening clip…');
      try {
        const info = await backend.probe(path);
        setClip({ path, url: backend.videoUrl(path), info, proxied: false });
        setCaptions([]);
        setSelectedCaptionId(null);
      } catch (e) {
        setError(message(e));
      } finally {
        setBusy(null);
      }
    },
    [backend],
  );

  useEffect(() => backend.onFileDrop((p) => void loadClip(p)), [backend, loadClip]);

  const onVideoError = useCallback(async () => {
    if (!clip) return;
    if (clip.proxied) {
      setError("This video can't be previewed.");
      return;
    }
    setBusy('Preparing preview…');
    try {
      const proxy = await backend.makeProxy(clip.path);
      setClip({ ...clip, url: backend.videoUrl(proxy), proxied: true });
    } catch (e) {
      setError(`Preview failed: ${message(e)}`);
    } finally {
      setBusy(null);
    }
  }, [backend, clip]);

  const openEditor = (p: Preset) => {
    if (!clip) {
      setError('Open a clip first so the editor has a frame to show.');
      return;
    }
    setDraft(p);
  };

  async function saveDraft() {
    if (!draft) return;
    const r = validatePreset(draft);
    if (!r.ok) {
      setError(r.error);
      return;
    }
    await backend.savePreset(r.preset);
    await refreshPresets();
    setPresetId(r.preset.id);
    setDraft(null);
  }

  async function deletePreset(id: string) {
    await backend.deletePreset(id);
    if (presetId === id) setPresetId(BUILTIN_PRESETS[0].id);
    await refreshPresets();
  }

  async function importPreset() {
    const text = await backend.importPreset();
    if (text === null) return;
    let raw: unknown;
    try {
      raw = JSON.parse(text);
    } catch {
      setError('Import failed: not a JSON file.');
      return;
    }
    const r = validatePreset(raw);
    if (!r.ok) {
      setError(`Import failed: ${r.error}`);
      return;
    }
    const p = { ...r.preset, id: crypto.randomUUID(), builtin: false };
    await backend.savePreset(p);
    await refreshPresets();
    setPresetId(p.id);
  }

  async function openClip() {
    const p = await backend.pickClip();
    if (p) void loadClip(p);
  }

  return (
    <div className="app">
      <PresetRail
        presets={allPresets}
        selectedId={preset.id}
        warnings={warnings}
        onSelect={setPresetId}
        onNew={() => openEditor(blankPreset(crypto.randomUUID()))}
        onEditCopy={(p) => openEditor(duplicatePreset(p, crypto.randomUUID()))}
        onEdit={(p) => openEditor(structuredClone(p))}
        onDelete={(id) => void deletePreset(id)}
        onImport={() => void importPreset()}
        onExport={(p) => void backend.exportPreset(p)}
      />
      <main className="stage">
        {clip ? (
          <>
            <video key={clip.url} ref={setVideo} src={clip.url} className="source-video" preload="auto" onError={() => void onVideoError()} />
            <PreviewCanvas
              video={video}
              info={clip.info}
              preset={preset}
              captions={captions}
              selectedCaptionId={selectedCaptionId}
              onSelectCaption={setSelectedCaptionId}
              onCaptionChange={(c) => setCaptions((list) => updateCaption(list, c))}
            />
            <button className="link" onClick={() => void openClip()}>Open another clip…</button>
          </>
        ) : (
          <div className="dropzone">
            <h1>Drop a clip</h1>
            <p>or</p>
            <button onClick={() => void openClip()}>Open clip…</button>
          </div>
        )}
        {busy && <div className="notice">{busy}</div>}
        {error && (
          <div className="notice error" role="alert">
            {error} <button onClick={() => setError(null)}>Dismiss</button>
          </div>
        )}
      </main>
    </div>
  );
}
```

```ts
import type { Trim } from '../types';

export const MIN_TRIM = 0.5;

const clamp = (v: number, lo: number, hi: number) => Math.min(hi, Math.max(lo, v));

export const fullTrim = (duration: number): Trim => ({ inS: 0, outS: duration });

export function setIn(trim: Trim, t: number, duration: number): Trim {
  if (duration <= MIN_TRIM) return fullTrim(duration);
  return { inS: clamp(t, 0, trim.outS - MIN_TRIM), outS: trim.outS };
}

export function setOut(trim: Trim, t: number, duration: number): Trim {
  if (duration <= MIN_TRIM) return fullTrim(duration);
  return { inS: trim.inS, outS: clamp(t, trim.inS + MIN_TRIM, duration) };
}

export function parseFps(fps: string): number {
  const [n, d] = fps.split('/').map(Number);
  const v = d === undefined ? n : n / d;
  return Number.isFinite(v) && v > 0 ? v : 60;
}

export function formatTime(s: number): string {
  const tenths = Math.round(s * 10);
  const m = Math.floor(tenths / 600);
  const rest = (tenths % 600) / 10;
  return `${m}:${rest.toFixed(1).padStart(4, '0')}`;
}
```

```ts
import { useEffect } from 'react';
import { parseFps, setIn, setOut } from '../state/trim';
import type { ClipInfo, Trim } from '../types';

export function useTrimKeys(video: HTMLVideoElement | null, info: ClipInfo | null, trim: Trim, setTrim: (t: Trim) => void, enabled: boolean) {
  useEffect(() => {
    if (!video || !info || !enabled) return;
    const onKey = (e: KeyboardEvent) => {
      const el = e.target as HTMLElement | null;
      if (el && (el.tagName === 'INPUT' || el.tagName === 'TEXTAREA' || el.tagName === 'SELECT' || el.isContentEditable)) return;
      const step = 1 / parseFps(info.fps);
      if (e.key === 'i' || e.key === 'I') setTrim(setIn(trim, video.currentTime, info.duration));
      else if (e.key === 'o' || e.key === 'O') setTrim(setOut(trim, video.currentTime, info.duration));
      else if (e.key === ' ') {
        e.preventDefault();
        if (video.paused) void video.play();
        else video.pause();
      } else if (e.key === 'ArrowLeft') {
        video.pause();
        video.currentTime = Math.max(0, video.currentTime - step);
      } else if (e.key === 'ArrowRight') {
        video.pause();
        video.currentTime = Math.min(info.duration, video.currentTime + step);
      }
    };
    window.addEventListener('keydown', onKey);
    return () => window.removeEventListener('keydown', onKey);
  }, [video, info, trim, setTrim, enabled]);
}
```

```ts
import type { Rect } from '../types';

export type Handle = 'move' | 'nw' | 'ne' | 'sw' | 'se';
export interface Guides { x: number[]; y: number[] }
export const MIN_SIZE = 8;

const clamp = (v: number, lo: number, hi: number) => Math.min(hi, Math.max(lo, v));
const r5 = (v: number) => Math.round(v * 1e5) / 1e5;

export const fracToPx = (r: Rect, w: number, h: number): Rect => [r[0] * w, r[1] * h, r[2] * w, r[3] * h];
export const pxToFrac = (r: Rect, w: number, h: number): Rect => [r5(r[0] / w), r5(r[1] / h), r5(r[2] / w), r5(r[3] / h)];

export function hitRect(rects: { id: string; rect: Rect }[], x: number, y: number, handleSize: number): { id: string; handle: Handle } | null {
  for (let i = rects.length - 1; i >= 0; i--) {
    const [rx, ry, rw, rh] = rects[i].rect;
    const corners: [Handle, number, number][] = [
      ['nw', rx, ry],
      ['ne', rx + rw, ry],
      ['sw', rx, ry + rh],
      ['se', rx + rw, ry + rh],
    ];
    for (const [handle, cx, cy] of corners) {
      if (Math.abs(x - cx) <= handleSize && Math.abs(y - cy) <= handleSize) return { id: rects[i].id, handle };
    }
    if (x >= rx && x <= rx + rw && y >= ry && y <= ry + rh) return { id: rects[i].id, handle: 'move' };
  }
  return null;
}

export function dragRect(start: Rect, handle: Handle, dx: number, dy: number, bw: number, bh: number): Rect {
  const [x, y, w, h] = start;
  if (handle === 'move') return [clamp(x + dx, 0, bw - w), clamp(y + dy, 0, bh - h), w, h];
  let l = x;
  let t = y;
  let r = x + w;
  let b = y + h;
  if (handle.includes('w')) l = clamp(x + dx, 0, r - MIN_SIZE);
  if (handle.includes('e')) r = clamp(r + dx, l + MIN_SIZE, bw);
  if (handle.includes('n')) t = clamp(y + dy, 0, b - MIN_SIZE);
  if (handle.includes('s')) b = clamp(b + dy, t + MIN_SIZE, bh);
  return [l, t, r - l, b - t];
}

function nearestDelta(values: number[], targets: number[], th: number): number | null {
  let best: number | null = null;
  for (const v of values) {
    for (const t of targets) {
      const d = t - v;
      if (Math.abs(d) <= th && (best === null || Math.abs(d) < Math.abs(best))) best = d;
    }
  }
  return best;
}

export function snapRect(rect: Rect, handle: Handle, guides: Guides, th: number, bw: number, bh: number): Rect {
  let [x, y, w, h] = rect;
  if (handle === 'move') {
    const ddx = nearestDelta([x, x + w / 2, x + w], guides.x, th);
    if (ddx !== null) x = clamp(x + ddx, 0, bw - w);
    const ddy = nearestDelta([y, y + h / 2, y + h], guides.y, th);
    if (ddy !== null) y = clamp(y + ddy, 0, bh - h);
    return [x, y, w, h];
  }
  let l = x;
  let t = y;
  let r = x + w;
  let b = y + h;
  const edge = (value: number, targets: number[], ok: (v: number) => boolean) => {
    const d = nearestDelta([value], targets, th);
    return d !== null && ok(value + d) ? value + d : value;
  };
  if (handle.includes('w')) l = edge(l, guides.x, (v) => r - v >= MIN_SIZE);
  if (handle.includes('e')) r = edge(r, guides.x, (v) => v - l >= MIN_SIZE);
  if (handle.includes('n')) t = edge(t, guides.y, (v) => b - v >= MIN_SIZE);
  if (handle.includes('s')) b = edge(b, guides.y, (v) => v - t >= MIN_SIZE);
  return [l, t, r - l, b - t];
}

export function guidesFor(bw: number, bh: number, others: Rect[]): Guides {
  return {
    x: [0, bw / 2, bw, ...others.flatMap((o) => [o[0], o[0] + o[2]])],
    y: [0, bh / 2, bh, ...others.flatMap((o) => [o[1], o[1] + o[3]])],
  };
}

export function nudgeRect(rect: Rect, key: string, step: number, bw: number, bh: number): Rect | null {
  const d: Record<string, [number, number]> = { ArrowLeft: [-step, 0], ArrowRight: [step, 0], ArrowUp: [0, -step], ArrowDown: [0, step] };
  const v = d[key];
  return v ? dragRect(rect, 'move', v[0], v[1], bw, bh) : null;
}
```

```ts
import { CANVAS_H, CANVAS_W, type Caption, type ClipInfo, type Overlay, type Preset } from '../types';
import { drawCaption } from './captions';
import { drawLayerBorder, drawMask } from './compose';

import { layoutLayer } from './fit';

export type CanvasFactory = (w: number, h: number) => { ctx: Ctx2D; encode(): Promise<string> };

async function blobToBase64(b: Blob): Promise<string> {
  const bytes = new Uint8Array(await b.arrayBuffer());
  let s = '';
  for (let i = 0; i < bytes.length; i += 0x8000) s += String.fromCharCode(...bytes.subarray(i, i + 0x8000));
  return btoa(s);
}

export const offscreenFactory: CanvasFactory = (w, h) => {
  const canvas = new OffscreenCanvas(w, h);
  const ctx = canvas.getContext('2d');
  if (!ctx) throw new Error('OffscreenCanvas 2D context unavailable');
  return { ctx, encode: async () => blobToBase64(await canvas.convertToBlob({ type: 'image/png' })) };
};

/** Renders with the same drawing code as the preview so the exported video matches it. */
export async function buildExportAssets(
  preset: Preset,
  clip: ClipInfo,
  captions: Caption[],
  make: CanvasFactory = offscreenFactory,
): Promise<{ layerMasks: Record<string, string>; overlays: Overlay[] }> {
  const layerMasks: Record<string, string> = {};
  for (const l of preset.layers) {
    if (!l.radius || l.radius <= 0) continue;
    const { draw } = layoutLayer(l, clip.width, clip.height);
    const c = make(draw[2], draw[3]);
    drawMask(c.ctx, draw[2], draw[3], l.radius);
    layerMasks[l.id] = await c.encode();
  }

  const overlays: Overlay[] = [];
  if (preset.layers.some((l) => l.border)) {
    const c = make(CANVAS_W, CANVAS_H);
    for (const l of preset.layers) drawLayerBorder(c.ctx, clip.width, clip.height, l);
    overlays.push({ pngBase64: await c.encode(), start: 0 });
  }
  for (const cap of captions) {
    if (!cap.text.trim()) continue;
    const c = make(CANVAS_W, CANVAS_H);
    drawCaption(c.ctx, cap);
    overlays.push({ pngBase64: await c.encode(), start: cap.start });
  }
  return { layerMasks, overlays };
}
```

```ts
import type { ClipInfo, ExportError, ExportJob, Overlay, Preset, Quality, Trim } from '../types';

export function buildExportJob(a: {
  source: string;
  clip: ClipInfo;
  preset: Preset;
  trim: Trim;
  quality: Quality;
  assets: { layerMasks: Record<string, string>; overlays: Overlay[] };
  outputDir: string | null;
}): ExportJob {
  return {
    source: a.source,
    clip: a.clip,
    preset: a.preset,
    trim: a.trim,
    quality: a.quality,
    layerMasks: a.assets.layerMasks,
    overlays: a.assets.overlays.filter((o) => o.start < a.trim.outS),
    outputDir: a.outputDir,
  };
}

export function toExportError(e: unknown): ExportError {
  if (e && typeof e === 'object' && 'code' in e && 'message' in e) return e as ExportError;
  const details = e instanceof Error ? `${e.message}\n${e.stack ?? ''}` : String(e);
  return { code: 'ffmpeg', message: 'Export failed.', details };
}
```

```rust
pub fn is_hex_color(s: &str) -> bool {
    s.len() == 7 && s.starts_with('#') && s[1..].chars().all(|c| c.is_ascii_hexdigit())
}

pub fn validate(p: &Preset) -> Result<(), String> {
    if p.version != 1 {
        return Err(format!("unsupported preset version {}", p.version));
    }
    if p.layers.is_empty() {
        return Err("preset needs at least one layer".into());
    }
    match &p.background {
        Background::Blur { amount } if !(0.0..=100.0).contains(amount) => return Err("blur amount must be 0-100".into()),
        Background::Color { color } if !is_hex_color(color) => return Err(format!("bad background color {color}")),
        _ => {}
    }
    let mut seen = std::collections::HashSet::new();
    for l in &p.layers {
        if !seen.insert(l.id.as_str()) {
            return Err(format!("duplicate layer id {}", l.id));
        }
        let [x, y, w, h] = l.src;
        if !(x >= 0.0 && y >= 0.0 && w > 0.0 && h > 0.0 && x + w <= 1.0 + 1e-6 && y + h <= 1.0 + 1e-6) {
            return Err(format!("layer {}: src outside frame", l.id));
        }
        let [dx, dy, dw, dh] = l.dst;
        if !(dx >= 0.0 && dy >= 0.0 && dw >= 1.0 && dh >= 1.0 && dx + dw <= CANVAS_W && dy + dh <= CANVAS_H) {
            return Err(format!("layer {}: dst outside canvas", l.id));
        }
        if let Some(r) = l.radius {
            if !(r >= 0.0 && r.is_finite()) {
                return Err(format!("layer {}: radius must be >= 0", l.id));
            }
        }
        if let Some(b) = &l.border {
            if !(b.width > 0.0 && is_hex_color(&b.color)) {
                return Err(format!("layer {}: bad border", l.id));
            }
        }
    }
    Ok(())
}

fn r(v: f64) -> i64 {
    v.round() as i64
}

/// Mirrors src/render/fit.ts `layoutLayer` exactly. Change both together.
pub fn layout_layer(src: [f64; 4], dst: [f64; 4], fit: Fit, sw: i64, sh: i64) -> LayerLayout {
    let mut x = r(src[0] * sw as f64).clamp(0, sw - 1);
    let mut y = r(src[1] * sh as f64).clamp(0, sh - 1);
    let mut w = r(src[2] * sw as f64).clamp(1, sw - x);
    let mut h = r(src[3] * sh as f64).clamp(1, sh - y);
    let (dx, dy, dw, dh) = (r(dst[0]), r(dst[1]), r(dst[2]), r(dst[3]));
    match fit {
        Fit::Cover => {
            let a = dw as f64 / dh as f64;
            if w as f64 / h as f64 > a {
                let nw = r(h as f64 * a).max(1);
                x += r((w - nw) as f64 / 2.0);
                w = nw;
            } else {
                let nh = r(w as f64 / a).max(1);
                y += r((h - nh) as f64 / 2.0);
                h = nh;
            }
            LayerLayout { crop: [x, y, w, h], draw: [dx, dy, dw, dh] }
        }
        Fit::Contain => {
            let s = (dw as f64 / w as f64).min(dh as f64 / h as f64);
            let draw_w = r(w as f64 * s).max(1);
            let draw_h = r(h as f64 * s).max(1);
            LayerLayout {
                crop: [x, y, w, h],
                draw: [dx + r((dw - draw_w) as f64 / 2.0), dy + r((dh - draw_h) as f64 / 2.0), draw_w, draw_h],
            }
        }
    }
}
```

```rust
use serde::Serialize;

use crate::job::Quality;

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize)]
pub enum Encoder {
    Nvenc,
    Amf,
    Qsv,
    X264,
    OpenH264,
}

pub const GPU: [Encoder; 3] = [Encoder::Nvenc, Encoder::Amf, Encoder::Qsv];
pub const CPU: [Encoder; 2] = [Encoder::X264, Encoder::OpenH264];

fn s(v: &[&str]) -> Vec<String> {
    v.iter().map(|x| x.to_string()).collect()
}

impl Encoder {
    pub fn ffmpeg_name(self) -> &'static str {
        match self {
            Encoder::Nvenc => "h264_nvenc",
            Encoder::Amf => "h264_amf",
            Encoder::Qsv => "h264_qsv",
            Encoder::X264 => "libx264",
            Encoder::OpenH264 => "libopenh264",
        }
    }

    pub fn is_gpu(self) -> bool {
        GPU.contains(&self)
    }

    pub fn args(self, q: Quality) -> Vec<String> {
        let hi = q == Quality::High;
        match self {
            Encoder::Nvenc => s(&["-c:v", "h264_nvenc", "-preset", "p5", "-rc", "vbr", "-cq", if hi { "19" } else { "26" }, "-b:v", "0"]),
            Encoder::Amf => {
                let qp = if hi { "20" } else { "27" };
                s(&["-c:v", "h264_amf", "-quality", "quality", "-rc", "cqp", "-qp_i", qp, "-qp_p", qp])
            }
            Encoder::Qsv => s(&["-c:v", "h264_qsv", "-global_quality", if hi { "20" } else { "27" }]),
            Encoder::X264 => s(&["-c:v", "libx264", "-preset", "medium", "-crf", if hi { "18" } else { "24" }]),
            Encoder::OpenH264 => s(&["-c:v", "libopenh264", "-b:v", if hi { "12M" } else { "6M" }]),
        }
    }
}

pub trait Runner {
    fn succeeds(&self, args: &[String]) -> bool;
}

/// One-frame test encode; a GPU encoder listed by ffmpeg can still fail without the right hardware/driver.
pub fn probe_args(enc: Encoder) -> Vec<String> {
    s(&["-hide_banner", "-nostdin", "-f", "lavfi", "-i", "color=c=black:s=256x256:d=0.1", "-frames:v", "1", "-c:v", enc.ffmpeg_name(), "-f", "null", "-"])
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)]
pub struct EncoderSet {
    pub gpu: Option<Encoder>,
    pub cpu: Option<Encoder>,
}

impl EncoderSet {
    pub fn primary(&self) -> Option<Encoder> {
        self.gpu.or(self.cpu)
    }

    pub fn fallback_for(&self, used: Encoder) -> Option<Encoder> {
        if used.is_gpu() {
            self.cpu
        } else {
            None
        }
    }
}

pub fn detect(runner: &dyn Runner) -> EncoderSet {
    EncoderSet {
        gpu: GPU.into_iter().find(|e| runner.succeeds(&probe_args(*e))),
        cpu: CPU.into_iter().find(|e| runner.succeeds(&probe_args(*e))),
    }
}
```

```rust
fn parse_fps(s: &str) -> Option<f64> {
    let v = match s.split_once('/') {
        Some((n, d)) => {
            let n: f64 = n.parse().ok()?;
            let d: f64 = d.parse().ok()?;
            if d == 0.0 {
                return None;
            }
            n / d
        }
        None => s.parse().ok()?,
    };
    (v.is_finite() && v > 0.0).then_some(v)
}

pub fn output_fps(fps: &str) -> String {
    match parse_fps(fps) {
        Some(v) if v <= 60.0 + 1e-6 => fps.to_string(),
        _ => "60".into(),
    }
}

pub fn build_filter(job: &ExportJob, masks: &HashMap<&str, usize>, overlays: &[(usize, f64)], fps: &str) -> String {
    let p = &job.preset;
    let (sw, sh) = (job.clip.width as i64, job.clip.height as i64);
    let layouts: Vec<LayerLayout> = p.layers.iter().map(|l| layout_layer(l.src, l.dst, l.fit, sw, sh)).collect();
    let mut parts: Vec<String> = Vec::new();

    let mut split = format!("[0:v]split={}[bgsrc]", p.layers.len() + 1);
    for i in 0..p.layers.len() {
        split.push_str(&format!("[s{i}]"));
    }
    parts.push(split);

    parts.push(match &p.background {
        Background::Blur { amount } => format!(
            "[bgsrc]scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,scale=270:480,gblur=sigma={},scale=1080:1920[bg]",
            secs(amount / 4.0)
        ),
        Background::Color { color } => format!("[bgsrc]scale=1080:1920,drawbox=x=0:y=0:w=iw:h=ih:color={color}:t=fill[bg]"),
        Background::None => "[bgsrc]scale=1080:1920,drawbox=x=0:y=0:w=iw:h=ih:color=black:t=fill[bg]".into(),
    });

    for (i, (l, lay)) in p.layers.iter().zip(&layouts).enumerate() {
        let [cx, cy, cw, ch] = lay.crop;
        let [_, _, dw, dh] = lay.draw;
        let base = format!("[s{i}]crop={cw}:{ch}:{cx}:{cy},scale={dw}:{dh}");
        match masks.get(l.id.as_str()) {
            Some(m) => {
                parts.push(format!("{base},format=rgba[l{i}p]"));
                parts.push(format!("[{m}:v]format=gray,scale={dw}:{dh}[m{i}]"));
                parts.push(format!("[l{i}p][m{i}]alphamerge[l{i}]"));
            }
            None => parts.push(format!("{base}[l{i}]")),
        }
    }

    let mut last = "bg".to_string();
    for (i, lay) in layouts.iter().enumerate() {
        parts.push(format!("[{last}][l{i}]overlay=x={}:y={}[c{i}]", lay.draw[0], lay.draw[1]));
        last = format!("c{i}");
    }
    for (k, (input, rel)) in overlays.iter().enumerate() {
        let enable = if *rel > 0.0005 { format!(":enable='gte(t,{})'", secs(*rel)) } else { String::new() };
        parts.push(format!("[{last}][{input}:v]overlay=x=0:y=0{enable}[o{k}]"));
        last = format!("o{k}");
    }
    parts.push(format!("[{last}]fps={fps},format=yuv420p[vout]"));
    parts.join(";")
}

pub fn build_args(job: &ExportJob, masks: &[(String, PathBuf)], overlays: &[(PathBuf, f64)], enc: Encoder, out: &Path) -> Vec<String> {
    let dur = job.trim.out_s - job.trim.in_s;
    let fps = output_fps(&job.clip.fps);
    let mut args: Vec<String> = ["-hide_banner", "-nostdin", "-y", "-nostats", "-progress", "pipe:1"].map(String::from).to_vec();
    args.extend(["-ss".into(), secs(job.trim.in_s), "-t".into(), secs(dur), "-i".into(), job.source.clone()]);

    let still = |args: &mut Vec<String>, p: &Path| {
        args.extend(["-loop".into(), "1".into(), "-framerate".into(), fps.clone(), "-t".into(), secs(dur), "-i".into(), p.to_string_lossy().into_owned()]);
    };
    let mut next = 1usize;
    let mut mask_inputs: HashMap<&str, usize> = HashMap::new();
    for (id, p) in masks {
        still(&mut args, p);
        mask_inputs.insert(id.as_str(), next);
        next += 1;
    }
    let mut overlay_inputs = Vec::new();
    for (p, start) in overlays {
        if *start >= job.trim.out_s {
            continue;
        }
        still(&mut args, p);
        overlay_inputs.push((next, (start - job.trim.in_s).max(0.0)));
        next += 1;
    }

    args.push("-filter_complex".into());
    args.push(build_filter(job, &mask_inputs, &overlay_inputs, &fps));
    args.extend(["-map", "[vout]", "-map", "0:a?"].map(String::from));
    args.extend(enc.args(job.quality));
    args.extend(["-c:a", "aac", "-b:a", "192k", "-movflags", "+faststart"].map(String::from));
    args.push(out.to_string_lossy().into_owned());
    args
}
```

```rust
    let v: serde_json::Value = serde_json::from_str(json).map_err(|e| e.to_string())?;
    let streams = v["streams"].as_array().ok_or("no streams")?;
    let video = streams.iter().find(|s| s["codec_type"] == "video").ok_or("no video stream")?;
    let width = video["width"].as_u64().ok_or("no width")? as u32;
    let height = video["height"].as_u64().ok_or("no height")? as u32;
    let fps = [&video["avg_frame_rate"], &video["r_frame_rate"]]
        .iter()
        .filter_map(|f| f.as_str())
        .find(|f| !f.starts_with("0/") && !f.is_empty())
        .unwrap_or("60")
        .to_string();
    let parse = |d: &serde_json::Value| d.as_str().and_then(|s| s.parse::<f64>().ok());
    let duration = parse(&v["format"]["duration"]).or_else(|| parse(&video["duration"])).ok_or("no duration")?;

    })
```

```rust
    let v = line.strip_prefix("out_time_us=").or_else(|| line.strip_prefix("out_time_ms="))?;
```

```rust
use serde::Serialize;

#[derive(Debug, Clone, Serialize)]
pub struct RawPresetFile {
    pub file: String,
    pub contents: String,
}

pub fn valid_id(id: &str) -> bool {
    !id.is_empty() && id.len() <= 100 && id.chars().all(|c| c.is_ascii_alphanumeric() || c == '-' || c == '_')
}

pub fn list(dir: &Path) -> Result<Vec<RawPresetFile>, String> {
    if !dir.exists() {
        return Ok(vec![]);
    }
    let mut out = Vec::new();
    for entry in std::fs::read_dir(dir).map_err(|e| e.to_string())? {
        let path = entry.map_err(|e| e.to_string())?.path();
        if path.extension().and_then(|e| e.to_str()) != Some("json") {
            continue;
        }
        let file = path.file_name().unwrap().to_string_lossy().into_owned();
        // Unreadable files come back empty so the UI lists them as a warning.
        let contents = std::fs::read_to_string(&path).unwrap_or_default();
        out.push(RawPresetFile { file, contents });
    }
    out.sort_by(|a, b| a.file.cmp(&b.file));
    Ok(out)
}

pub fn save(dir: &Path, id: &str, contents: &str) -> Result<(), String> {
    if !valid_id(id) {
        return Err(format!("invalid preset id {id}"));
    }
    std::fs::create_dir_all(dir).map_err(|e| e.to_string())?;
    std::fs::write(dir.join(format!("{id}.json")), contents).map_err(|e| e.to_string())
}

pub fn delete(dir: &Path, id: &str) -> Result<(), String> {
    if !valid_id(id) {
        return Err(format!("invalid preset id {id}"));
    }
    std::fs::remove_file(dir.join(format!("{id}.json"))).map_err(|e| e.to_string())
```

```rust
use std::collections::hash_map::DefaultHasher;
use std::hash::{Hash, Hasher};
use std::path::{Path, PathBuf};
use std::process::Stdio;

use crate::encoders::Encoder;
use crate::ffmpeg::tool_command;
use crate::job::Quality;

pub fn proxy_path(cache: &Path, source: &Path) -> PathBuf {
    let mut h = DefaultHasher::new();
    source.hash(&mut h);
    if let Ok(m) = std::fs::metadata(source) {
        m.len().hash(&mut h);
        if let Ok(t) = m.modified() {
            t.hash(&mut h);
        }
    }
    cache.join("proxies").join(format!("{:016x}.mp4", h.finish()))
}

/// 720p H.264 copy for previewing codecs WebView2 can't play (e.g. HEVC without the Store extension).
pub fn make_proxy_file(cache: &Path, source: &Path, enc: Encoder) -> Result<PathBuf, String> {
    let out = proxy_path(cache, source);
    if out.exists() {
        return Ok(out);
    }
    std::fs::create_dir_all(out.parent().unwrap()).map_err(|e| e.to_string())?;
    let part = out.with_extension("part.mp4");
    let mut args: Vec<String> = ["-hide_banner", "-nostdin", "-y", "-i"].map(String::from).to_vec();
    args.push(source.to_string_lossy().into_owned());
    args.extend(["-vf", "scale=-2:720"].map(String::from));
    args.extend(enc.args(Quality::Small));
    args.extend(["-c:a", "aac", "-b:a", "128k", "-movflags", "+faststart"].map(String::from));
    args.push(part.to_string_lossy().into_owned());
    let out_put = tool_command("ffmpeg").args(&args).stdin(Stdio::null()).output().map_err(|e| format!("Couldn't run ffmpeg: {e}"))?;
    if !out_put.status.success() {
        let _ = std::fs::remove_file(&part);
        let err = String::from_utf8_lossy(&out_put.stderr);
        return Err(format!("Couldn't prepare a preview.\n{}", err.lines().rev().take(20).collect::<Vec<_>>().join("\n")));
```

```rust
fn io_err(e: impl std::fmt::Display) -> ExportError {
    ExportError::new("io", "Couldn't prepare export files.", &e.to_string())

pub fn write_assets(job: &ExportJob, dir: &Path) -> Result<WrittenAssets, ExportError> {
    std::fs::create_dir_all(dir).map_err(io_err)?;
    let b64 = base64::engine::general_purpose::STANDARD;
    let mut masks = Vec::new();
    for (i, layer) in job.preset.layers.iter().enumerate() {
        if let Some(data) = job.layer_masks.get(&layer.id) {
            let p = dir.join(format!("mask-{i}.png"));
            std::fs::write(&p, b64.decode(data).map_err(io_err)?).map_err(io_err)?;
            masks.push((layer.id.clone(), p));
        }
    }
    let mut overlays = Vec::new();
    for (i, o) in job.overlays.iter().enumerate() {
        let p = dir.join(format!("overlay-{i}.png"));
        std::fs::write(&p, b64.decode(&o.png_base64).map_err(io_err)?).map_err(io_err)?;
        overlays.push((p, o.start));
    }
    Ok(WrittenAssets { masks, overlays })
}

fn run_once(job: &ExportJob, assets: &WrittenAssets, enc: Encoder, out: &Path, state: &ExportState, on_progress: &dyn Fn(ExportProgress)) -> Result<(), ExportError> {
    let args = build_args(job, &assets.masks, &assets.overlays, enc, out);
    let mut child = tool_command("ffmpeg")
        .args(&args)
        .stdin(Stdio::null())
        .stdout(Stdio::piped())
        .stderr(Stdio::piped())
        .spawn()
        .map_err(|e| ExportError::new("ffmpeg", "Couldn't start ffmpeg.", &e.to_string()))?;
    let stdout = child.stdout.take().expect("stdout piped");
    let stderr = child.stderr.take().expect("stderr piped");

    let tail = Arc::new(Mutex::new(VecDeque::with_capacity(STDERR_LINES)));
    let tail_w = Arc::clone(&tail);
    let err_thread = std::thread::spawn(move || {
        for line in BufReader::new(stderr).lines().map_while(Result::ok) {
            let mut t = tail_w.lock().unwrap();
            if t.len() == STDERR_LINES {
                t.pop_front();
            }
            t.push_back(line);
        }
    });

    *state.child.lock().unwrap() = Some(child);
    if state.cancelled.load(Ordering::SeqCst) {
        state.cancel(); // cancel arrived while spawning
    }

    let total_us = (job.trim.out_s - job.trim.in_s) * 1_000_000.0;
    let started = Instant::now();
    for line in BufReader::new(stdout).lines().map_while(Result::ok) {
        if line == "progress=end" {
            on_progress(ExportProgress { fraction: 1.0, eta_s: Some(0.0) });
        } else if let Some(f) = parse_progress_line(&line, total_us) {
            on_progress(ExportProgress { fraction: f, eta_s: eta(started.elapsed().as_secs_f64(), f) });
        }
    }

    let child = state.child.lock().unwrap().take();
    let status = child.map(|mut c| c.wait());
    let _ = err_thread.join();

    if state.cancelled.load(Ordering::SeqCst) {
        return Err(ExportError::new("cancelled", "Export cancelled.", ""));
    }
    match status {
        Some(Ok(s)) if s.success() => Ok(()),
        other => {
            let tail = tail.lock().unwrap().iter().cloned().collect::<Vec<_>>().join("\n");
            let details = format!("encoder: {}\nstatus: {:?}\nargs: {}\n\n{}", enc.ffmpeg_name(), other.map(|r| r.map(|s| s.code())), args.join(" "), tail);
            Err(ExportError::new("ffmpeg", "Export failed.", &details))
        }
    }
}

pub fn run_export(job: ExportJob, encoders: &EncoderSet, work_root: &Path, state: &ExportState, on_progress: &dyn Fn(ExportProgress)) -> Result<ExportResult, ExportError> {
    validate(&job.preset).map_err(|e| ExportError::new("invalid_preset", "This preset can't be exported.", &e))?;
    let out_dir = match &job.output_dir {
        Some(d) => PathBuf::from(d),
        None => Path::new(&job.source).parent().map(Path::to_path_buf).unwrap_or_default(),
    };
    if !is_dir_writable(&out_dir) {
        return Err(ExportError::new("not_writable", "Can't save to this folder. Pick another one.", &out_dir.to_string_lossy()));
    }
    let primary = encoders.primary().ok_or_else(|| ExportError::new("ffmpeg", "No H.264 encoder found in the bundled ffmpeg.", ""))?;
    let out = unique_output_path(Path::new(&job.source), &out_dir);
    let stamp = SystemTime::now().duration_since(UNIX_EPOCH).map(|d| d.as_millis()).unwrap_or(0);
    let work = work_root.join(format!("export-{stamp}"));
    let assets = write_assets(&job, &work)?;

    state.cancelled.store(false, Ordering::SeqCst);
    let result = match run_once(&job, &assets, primary, &out, state, on_progress) {
        Ok(()) => Ok(false),
        Err(e) if e.code == "ffmpeg" => match encoders.fallback_for(primary) {
            Some(cpu) => {
                let _ = std::fs::remove_file(&out);
                run_once(&job, &assets, cpu, &out, state, on_progress).map(|_| true)
            }
            None => Err(e),
        },
        Err(e) => Err(e),
    };
    let _ = std::fs::remove_dir_all(&work);
    match result {
        Ok(used_cpu_fallback) => Ok(ExportResult { output_path: out.to_string_lossy().into_owned(), used_cpu_fallback }),
        Err(e) => {
            let _ = std::fs::remove_file(&out);
            Err(e)
        }
    }
}
```

```tsx
import { useState } from 'react';
import type { LoadedClip } from '../App';
import type { Backend } from '../backend/types';
import { buildExportAssets } from '../render/exportAssets';
import { ensureFonts } from '../render/fonts';
import { buildExportJob, toExportError } from '../state/exportJob';
import { formatTime } from '../state/trim';
import type { Caption, ExportError, ExportResult, Preset, Quality, Trim } from '../types';

type Status =
  | { kind: 'idle' }
  | { kind: 'running'; fraction: number; etaS: number | null }
  | { kind: 'done'; result: ExportResult }
  | { kind: 'error'; error: ExportError };

interface Props { backend: Backend; clip: LoadedClip; preset: Preset; trim: Trim; captions: Caption[] }

export function ExportPanel({ backend, clip, preset, trim, captions }: Props) {
  const [quality, setQuality] = useState<Quality>('high');
  const [outputDir, setOutputDir] = useState<string | null>(null);
  const [status, setStatus] = useState<Status>({ kind: 'idle' });

  async function run(dir: string | null): Promise<void> {
    setStatus({ kind: 'running', fraction: 0, etaS: null });
    try {
      await ensureFonts();
      const assets = await buildExportAssets(preset, clip.info, captions);
      const job = buildExportJob({ source: clip.path, clip: clip.info, preset, trim, quality, assets, outputDir: dir });
      const result = await backend.startExport(job, (p) => setStatus({ kind: 'running', fraction: p.fraction, etaS: p.etaS }));
      setStatus({ kind: 'done', result });
    } catch (e) {
      const err = toExportError(e);
      if (err.code === 'not_writable') {
        const picked = await backend.pickFolder();
        if (picked) {
          setOutputDir(picked);
          return run(picked);
        }
      }
      setStatus(err.code === 'cancelled' ? { kind: 'idle' } : { kind: 'error', error: err });
    }
  }

  const running = status.kind === 'running';

  return (
    <section className="panel">
      <h2>Export</h2>
      <fieldset disabled={running}>
        <legend>Quality</legend>
        <label>
          <input type="radio" name="quality" checked={quality === 'high'} onChange={() => setQuality('high')} /> High
        </label>
        <label>
          <input type="radio" name="quality" checked={quality === 'small'} onChange={() => setQuality('small')} /> Smaller file
        </label>
      </fieldset>
      <p className="hint">
        1080×1920 MP4 · {formatTime(trim.outS - trim.inS)} · saved {outputDir ? `to ${outputDir}` : 'next to the clip'}
      </p>
      {running ? (
        <div className="progress">
          <progress value={status.fraction} max={1} />
          <span>
            {Math.round(status.fraction * 100)}%{status.etaS !== null ? ` · ${Math.ceil(status.etaS)}s left` : ''}
          </span>
          <button onClick={() => void backend.cancelExport()}>Cancel</button>
        </div>
      ) : (
        <button className="primary" onClick={() => void run(outputDir)}>
          Export
        </button>
      )}
      {status.kind === 'done' && (
        <div className="done">
          <p>Saved: {status.result.outputPath}</p>
          {status.result.usedCpuFallback && <p className="hint">GPU encode failed, used CPU instead.</p>}
          <button onClick={() => void backend.revealFile(status.result.outputPath)}>Open folder</button>
        </div>
      )}
      {status.kind === 'error' && (
        <div className="notice-inline error" role="alert">
          <p>{status.error.message}</p>
          <button onClick={() => void navigator.clipboard?.writeText(status.error.details)}>Copy error details</button>
        </div>
      )}
    </section>
  );
}
```
